# Responsive Web Design

## Project Description
This project is a responsive website created using HTML and CSS. It demonstrates CSS Flexbox and Grid layouts and adapts to different screen sizes such as desktop, tablet, and mobile.

## Features
- Responsive navigation bar
- Header section
- Three boxes arranged using CSS Grid
- Photo gallery with six items
- Responsive layout for desktop, tablet, and mobile
- Footer section

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## Responsive Design
- Desktop: Three-column layout
- Tablet: Two-column layout
- Mobile: Single-column layout
